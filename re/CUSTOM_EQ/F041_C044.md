# Product 3-Band Custom EQ — C044 / F041 (Nothing X, source-verified)

## Packet
`CustomEQ` (`re/proto-src/com/nothing/earbase/equalizer/entity/CustomEQ.java`):
`[count(1)][totalGain f32 LE][per band: filterType(1), gain f32, freq f32, Q f32]`.
Quirk (CONFIRMED from code): the writer allocates `(size*16)+5` but fills only
5+13·n bytes, then returns the whole backing array — the on-wire packet is
**5+16·n bytes with 3·n trailing zero bytes** (`INDEX_STEP_SIXTY=16`), while the
parser `getCustomValues()` strides 13 (`INDEX_STEP_THIRTY=13`).
Types: LOW_SHELF 0, PEAK 1, HIGH_SHELF 2 (+LOW_PASS 3, HIGH_PASS 4).

## Bands (CONFIRMED)
Radar items Mid(type 1)/Treble(type 2)/Bass(type 0)
(`BaseEqualizerViewModel.java:169`).
Freq/Q per `getFreq`/`getQ`:
- Dirac VMs (espeon/girafarig/gligar/forretress/donphan): 140 Hz/Q 0.8,
  980 Hz/Q 0.66, 3500 Hz/Q 1.0 (espeon `:71-76,:457-480`; identical constants
  in the other four).
- Simple: 140/0.8, 980/0.7, 6900/1.0 (base `:545-567`;
  `IOTProductDeviceEspeon.getSimpleCustomEQParameter :105-118`).

## Flow (CONFIRMED — full chain)
Screen open → `register()` → GET 0xC044 (`getCustomEQData`, base `:323-408`) →
`updateCustomEQValue` → radar gains (`:835-866`).
Drag band → `onChange(index)` → `setCustomEQ(index)` builds
`CustomEQ.obtainDataPacket(-maxGain, [EQ(type,gain,freq,Q)×3])` (`:712-737,779`)
→ `customEQValue` SET 0xF041 via `syncSetResponse` (`:781-789`;
builder `TWSDeviceExtKt.java:554-561`: `setCommand(61505)`/`getCommand(49220)`)
→ on ACK refresh GET cache + `onUpdate` (`:804-815`).
`totalGain` is always recomputed as −(max band gain). Selecting type 6 sends
F01D `[06 00]` only (recall; no F041 involved).

## Worked example (source-derived, espeon, Bass +2.0 / Mid 0.0 / Treble −1.0)
53 bytes (5+16·3, incl. 9 trailing zero bytes): `[03]` + totalGain −2.0
(`00 00 00 C0`) +
`[00 | 00 00 00 40 | 00 00 0C 43 | CD CC 4C 3F]` (Bass 0/140/0.8) +
`[01 | 00 00 00 00 | 00 00 75 44 | 29 35 D1 3F]` (Mid 1/980/0.66) +
`[02 | 00 00 80 BF | 00 00 5B 45 | 00 00 80 3F]` (Treble 2/3500/1.0) +
`[00 × 9]` (allocation padding).
