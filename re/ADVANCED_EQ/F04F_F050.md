# 8-Band Advanced EQ — F04F / F050 (Nothing X, source-verified)

## Who uses it
Only `supportAdvanceEq()=true` products: EarTwo (Ear 2), EarThree B173 (Ear 3),
EarTwos B171 (Nothing Ear), Elekid B170 (Headphone 1). NOT the CMF Dirac line
(espeon/donphan/girafarig have no override → false).

## Packets
- Mode flag: `advanceCustomEQMode(ON)` SET 0xF04F `[01 00]`
  (`BaseEqualiserActivity$onInit$advanceTab$1$1.java:74-87`;
  builder `TWSDeviceExtKt.java:167-175`; `AdvanceCustomEQEntity.Mode` OFF 0/ON 1).
  Mode read C04C (unknown-generic `UnknownEqualizerViewModel.java:180,254-256`).
- Values: `advanceCustomEQValue(tws, profileIndex, EQEntity)` SET 0xF050
  (`AdvanceEQViewModel.sendProfileDataToDevice`, `…/AdvanceEQViewModel.java:1732-…,1785`;
  builder `:187-195`). Value GET 0xC04D takes getPayload `[profileIndex]`.

## `EQEntity` (`re/proto-src/com/nothing/core/entity/EQEntity.java`)
`SIZE=8` (`:40`); default freqs 55/110/220/440/1320/3300/6600/13200 Hz with
per-band min/max (`:29`); types LOW_SHELF 0/PEAK 1/HIGH_SHELF 2; `DEFAULT_Q=1.0`.
Packet `[profileIndex(1)][count(1)][totalGain f32][type(1),gain f32,freq f32,Q f32 ×n]`
= 6+n·13 (`:184-223`; parse `:66-99`).

## UI
`AdvanceEQViewModel` (2434 lines): profiles, undo/redo, wave chart, per-band
gain/freq/Q editing; `sendProfileDataToDevice` call sites `:869,:1007,:1726,:2171,:2238,:2307`.
